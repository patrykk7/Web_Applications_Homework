Nie z tego świata "Supernatural"

Strona internetowa poświęcona kultowemu serialowi fantasy „Supernatural”.
Projekt zawiera sekcję informacyjną o fabule serialu, galerię głównych postaci
z możliwością powiększania zdjęć oraz zestaw najciekawszych faktów i ciekawostek o uniwersum Winchesterów.

Projekt został wdrożony i jest dostępny publicznie za pośrednictwem GitHub Pages:
https://patrykk7.github.io/Web_Applications_Homework/

Wykorzystane technologie

* **HTML5**:
    * Semantyczny podział dokumentu (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
    * Standardy dostępności (atrybuty `alt`, `lang="pl"`)
* **CSS3**:
    * **CSS Grid** – ułożenie kart postaci w elastycznej siatce
    * **Flexbox** – układ paska nawigacyjnego oraz elementów w stopce
    * **Media Queries (`@media`)** – pełna responsywność dostosowana do ekranów komputerowych (1366 px) oraz telefonów (375–390 px)
    * Zmienne style dla motywu jasnego i ciemnego
    * Płynne przewijanie strony (`scroll-behavior: smooth`)
* **JavaScript**:
    * Przełącznik motywu ciemnego/jasnego (`classList.toggle`) z aktualizacją etykiety przycisku
    * Przycisk powrotu na górę strony (`window.scrollTo`)
    * Interaktywna galeria – pełnoekranowy podgląd zdjęć bohaterów wraz z przyciskiem zamykania
